# 项目配置约定 · 草案 1

这是新工程专用草案，以 `contract: knowledge-video-remotion` 区别旧配置。运行加载器及正式格式校验尚未实现。字段实现时可以调整，但须同步模板、文档和检查。

| 文件 | 内容 |
| --- | --- |
| project.json | 身份、工程版本、视频规格、主题、相对文件引用 |
| storyboard.json | 按顺序排列的片段、意图、时长、局部内容事件、场景类型 |
| captions.json | 字幕引用片段与局部事件，不重复维护全片秒数 |
| audio-plan.json | 沿用音频 schema 2 的空计划，混音器待迁移 |
| facts.md | 事实来源、简化边界、易误解点 |
| review.json | 事实、画面和声音的人工审阅状态 |
| scenes/ | 本期专属场景；需要时增加源码 |
| assets/index.json | 本期素材清单；默认无素材 |

## 时间

`storyboard.segments` 的数组顺序确定全片顺序，每段用 `durationSeconds` 表达时长。全片时长由片段相加得到，不在 project.json 再写一个可冲突的值。所有时间均为最终播放时间；新工程不设置全局 1.25 倍速。

事件键只需在片段内唯一。完整标识为 `片段id.事件id`，例如 `opening.reveal`。字幕引用本段事件或局部秒数，区间为左闭右开；允许留白，不自动压缩字幕来踩音乐拍子。此阶段模板用事件引用示范格式。

后续音频编译入口将完整事件标识映射到全片秒数，再交给原有 schema 2 编排算法。当前空音频计划不会涉及引用转换；不能认为旧音频编译器已直接支持新项目结构。

## 内容与画面

`sceneType` 选择表现形式，`themeId` 选择视觉风格；单期文字与参数属于本期配置。模板的 `placeholder` 场景尚未实现，不能把模板当作可播放成片。`paper-draft` 是配色草案，不表示字体或渲染已验证。

## 素材

原始文件在公共 `assets/` 或本期 `assets/` 中，由索引记录 id、相对路径、类型、来源和授权说明。生成的浏览器素材在 `public/prepared/`，最终混音和报告在 `outputs/`。索引内容与输出清单关联，避免只靠文件名寻找素材。

## 版本

`contractVersion` 是新配置格式版本；`templateVersion` 是创建本期时使用的工程版本；`audio-plan.schemaVersion` 是独立的音频格式版本。它们不能互相代替。旧配置需显式转换副本并核对时间，不接受仅替换版本字段的迁移。
