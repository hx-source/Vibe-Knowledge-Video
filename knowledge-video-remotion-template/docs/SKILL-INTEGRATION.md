# 与现有 Skill 的接入边界

现有 Skill 维护源在相邻 `skills/knowledge-video/`，当前适配旧工程 v0.3.0。本次未修改维护源或已安装版本。

新工程通过真实片段和完整旧案例验证后再接入，工作包括：

1. 更新 Skill 工程说明，明确新旧项目识别、Remotion 的预览/导出命令和迁移路径。
2. 修改定位脚本，支持新工程名称与经过验证的版本；存在多个工程时按显式选择处理，不能静默选错。
3. 保留内容驱动、连续配乐、音效用途及人工听感规则；删除只适用于旧 Canvas 入口的限制。
4. 用实际调用验证新建、加载、局部审片和导出，再更新版本与安装副本。

工程目录只保存这份接入说明，不复制第二套 SKILL.md。公共实现、配置格式的权威说明保留在工程；Skill 引用工程说明，避免两边内容逐渐不一致。
