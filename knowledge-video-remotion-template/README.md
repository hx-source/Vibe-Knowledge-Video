# 内容驱动知识视频 · Remotion 模板工程

当前版本：`0.1.0-alpha.0`。阶段：**目录与设计骨架已建立，Remotion 运行环境尚未接通**。

本工程承接旧 `knowledge-video-template` v0.3 的内容制作和音频规则，单独建立 Remotion 画面实现。旧工程保留在仓库外作为本地对照，本仓库不包含它。新工程版本独立编号，不代表旧工程降级。

## 当前可用范围

- 模块职责、数据流、迁移顺序和项目配置草案。
- 新一期的空白内容模板、静音音频计划、视觉主题草案。
- 无需安装第三方依赖的目录与配置检查：`npm run check:scaffold`。

尚未安装 React / Remotion，不能预览或导出视频；当前没有影片、已迁移的场景或声音样例。配置是新工程的初版约定，不保证兼容旧 CLI。骨架检查不等于渲染或听感验收。

## 从这里开始

1. 阅读 [工程结构](docs/ARCHITECTURE.md)。
2. 按 [迁移清单](docs/MIGRATION.md) 逐项实现，每一步更新状态与证据。
3. 修改数据格式前查看 [项目配置约定](docs/PROJECT-CONTRACT.md)。
4. 工程验证完成后，按 [Skill 接入说明](docs/SKILL-INTEGRATION.md) 更新现有 Skill。

## 目录

```text
src/
  compositions/  Remotion 注册、整片与片段入口
  components/    通用画面元素
  scenes/        可复用的讲解场景
  timeline/      内容事件、局部时间、帧转换
  themes/        字体、配色、版式与运动风格
  audio/         浏览器端音轨接入
  review/        带画面的局部检查和 A/B 播放
scripts/         本机加载、混音、导出和检查工具
templates/starter/  新一期的配置骨架
projects/        各期内容和专属素材
assets/          公共原始素材与来源索引
public/          供浏览器读取的素材准备目录
outputs/         按项目和修订保存的生成结果
tests/           后续实现所需的检查
docs/            设计、迁移和使用说明
releases/        验证后的版本快照
```

## 已确定的原则

- 内容决定讲解时间，音乐节拍仅作参考。
- 保持配乐连贯；音效描述内容事件，不要求所有动作发声。
- 开始和结束是用途标签，可以选不同声音；过程音默认关闭。
- 区分自动检查、人工观看、人工试听；未检查时不得写为通过。
- 公共能力进工程，单期选择进项目，制作方法进 Skill。
- 预览与导出必须共享时间轴、素材和混音来源。

旧工程和现有 Skill 仍按原方式工作。本工程通过迁移验收之前，不把 Skill 默认目标切到这里。
